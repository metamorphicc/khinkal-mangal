# Хинкал Мангал

Лендинг для грузинского ресторана, хинкальной и шашлычной в Междуреченске. Страница собрана под реальную задачу: быстро показать кухню, особенности заведения, контакты и собрать заявку на стол, доставку или заказ еды.

## Что внутри

- атмосферный первый экран в стиле ресторанного сайта;
- блок меню с основными направлениями кухни;
- особенности заведения: доставка, навынос, кофе с собой, детская комната, можно с собакой;
- галерея с крупными продуктовыми фото;
- честный блок про отзывы;
- форма заявки с отправкой в Telegram;
- контакты, адрес, телефон и ссылка на маршрут.

## Стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-подход к базовым UI-компонентам
- Lucide icons
- Framer Motion

## Запуск

```bash
npm install
npm run dev
```

Проект откроется на `http://localhost:3000`.

## Telegram

Создайте файл `.env.local` по примеру `.env.example`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_telegram_chat_id_here
```

После этого форма будет отправлять заявки в указанный Telegram-чат.

## Контент

Все основные тексты, контакты, ссылки и изображения лежат в:

```text
src/config/siteConfig.ts
```
